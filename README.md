# Acidentes por Escorpiões em Piracicaba (SP)

Este repositório reúne dados e códigos para a análise de séries temporais mensais de acidentes por escorpiões no município de Piracicaba, São Paulo, no período de 2014 a 2025.

Os dados são provenientes do Sistema de Informação de Agravos de Notificação (SINAN/DATASUS).

O projeto tem como objetivo investigar tendências temporais, padrões sazonais e estruturas de dependência, além de desenvolver e comparar modelos estatísticos para descrição e previsão do número de acidentes.

**Palavras-chave:** Escorpionismo, Séries Temporais, Modelos de Contagem, Poisson, Binomial Negativa, GARMA.
